# UG Wealth Hub

Mobile-friendly front-end website.

Files:
- index.html
- style.css
- script.js

The current version is a demo/information front end. It does not process real
deposits or withdrawals and does not guarantee returns.

The WhatsApp button is connected to the UG Wealth Hub group invite link supplied
by the site operator.

For a real financial service, add secure server-side authentication, a private
database, proper audit logs, and confirm applicable Ugandan legal/regulatory
requirements before handling customer funds.
